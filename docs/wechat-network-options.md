# 小程序网络与域名方案

当前生产 API、示例海报均使用 `https://www.yjchufa.com`，实测该域名直接返回，无 301/302；裸域 `https://yjchufa.com` 会跳转一次，因此不建议作为小程序合法域名。当前海报任务数据仍由应用接口读取，私有短期下载域名尚未完成。

ICP备案状态尚未从工信部官方查询得到可验证结果，必须视为提审阻断项。微信服务器域名通常要求 HTTPS，并在公众平台完成合法域名配置；腾讯云备案文档也要求先准备可备案域名与真实主体资料。[腾讯云备案准备](https://cloud.tencent.com/document/product/243/18905)

## 方案比较

| 方案 | 优点 | 风险/阻断 | 建议 |
|---|---|---|---|
| A. 继续 Vercel | 复用全部服务、成本最低、当前 Web 稳定 | 境外节点在大陆移动网络延迟与稳定性未知；ICP备案/微信域名审核需实际验证 | 开发与体验版优先，不能预先承诺审核通过 |
| B. 大陆合规 API 适配层 | 可使用备案域名和境内链路，改善稳定性 | 需要境内云资源、备案、运维、数据与安全评估；会增加一层协议 | 若 A 真机数据不合格，再小范围增加，不迁移核心数据库 |
| C. 微信云开发/云函数适配 | 与微信登录和小程序网络集成较自然 | 供应商绑定、函数限制、双平台日志与鉴权复杂；仍需安全访问现有服务 | 可作为登录/下载适配层候选，不复制核心业务和点数逻辑 |

下一步必须在中国大陆至少两家移动网络上记录登录、API、海报下载的 P50/P90、失败率，再决定是否采用 B 或 C。
