# 营业执照到手后的上线清单

## A 主体

- [ ] 核对执照真实主体、名称和经营范围；完成小程序主体注册/认证。
- [ ] 获取正式 AppID/AppSecret，仅写入 Vercel/微信平台密钥配置。验证：服务端 code2session 成功且日志不含身份原文。

## B 服务器与备案

- [ ] 确认 ICP/小程序备案真实状态；配置 HTTPS request/download 合法域名。
- [ ] 在中国大陆 iPhone/Android 对 API、海报下载做 Wi-Fi/5G/弱网实测。

## C 支付

- [ ] 申请微信支付商户号并绑定 AppID；配置商户号、序列号、APIv3 key、私钥和回调。
- [ ] 确认人民币点数包与退款规则后再设置金额和 enabled。
- [ ] 先沙箱/隔离环境，再做最小金额付款、验签、重复通知、退款、账本回滚测试。
- [ ] 全部通过并获用户明确确认后才可改支付生产开关。

## D 平台内容

- [ ] 选择与真实业务一致的服务类目；填写真实主体、客服、隐私保护指引和用户协议。
- [ ] 核验生成式 AI 服务备案/登记/标识要求；只有取得真实编号后才公开。

## E 测试

- [ ] 按 `device-test-checklist.md` 完成 DevTools、iPhone、Android、登录、生成、修改、海报、分享、点数。
- [ ] 验证支付关闭版与支付开启候选版均 fail closed；完成安全、依赖、密钥和数据库恢复演练。

## F 提审

- [ ] 上传体验版、设置体验成员、保存版本与 commit 对应关系。
- [ ] 提审前复核截图、功能说明、测试账号、隐私权限和客服入口；记录审核结论，不预先声称通过。
