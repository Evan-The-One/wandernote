# 0009 小程序只读分享

## 变更

新增 `trip_shares`，只保存不可逆的分享令牌哈希、创建者、状态和可选过期时间。公开接口只能通过有效令牌读取只读行程，不能读取账户、点数或海报权益。

迁移只允许通过部署迁移步骤或受控运维命令执行。任何公开 API 请求都不得创建或修改数据库结构。

## 上线

Vercel Production 构建运行 `pnpm build:vercel`，先执行 Drizzle migrations，再执行 Next.js 构建。Preview、本地构建不会自动迁移生产数据库。

## 回滚

应用回滚到 0008 代码前，先停止创建新分享；已有分享可保持只读。确认不再有代码访问该表后，人工执行：

```sql
DROP TABLE IF EXISTS trip_shares;
```

删除表会使已签发的小程序分享失效，不影响 `trips`、用户、点数和海报数据。生产回滚前必须先备份并记录操作人和时间。
