# 微信真实设备验收清单

## 前置

- 正式 AppID、开发者权限、request/download 合法域名已配置。
- 导入体验版，支付仍关闭；准备两个微信测试账号和非私人测试行程。

## iPhone

- 小屏与大屏、刘海/Dynamic Island、安全区、键盘顶起和返回。
- Wi-Fi/5G/弱网切换；生成中切后台、杀进程、重开后恢复 jobId。
- 海报多页预览；仅点“保存”时申请相册权限；拒绝后进入设置恢复。
- 分享给好友、撤销分享、只读访问、会话过期重新登录。

## Android

- 小屏与大屏、系统返回键、底部安全区、键盘收起。
- Wi-Fi/5G/弱网切换、后台恢复、网络失败后的重试。
- 相册权限首次拒绝和永久拒绝；多页逐张保存；分享与撤销。

## 共同业务

- 新建、修改活动、修改整天、整份重排、一次撤销、删除自己的攻略。
- 海报报价、点数不足、生成、刷新恢复、私有下载、失败返还。
- 账户、点数账本、退出登录、重新进入恢复同一身份。
- 错误仅显示中文行动建议；记录 requestId，不出现堆栈、openid 或签名 URL。

结果必须逐项记录机型、系统、微信版本、网络、时间和 requestId。浏览器模拟不计作真机通过。
