# 微信小程序点数支付分类审计

状态：**未确认，支付必须保持关闭**。

一键出发未来售卖的是点数，点数用于在线生成数字旅行海报；没有实体物流或线下履约。这种用途可能被微信认定为虚拟商品或虚拟服务。普通小程序支付与小程序虚拟支付不是同一套能力，最终必须以小程序后台向真实主体开放的能力、适用平台规则和审核结论为准。

在取得明确结论前：

- 不使用普通 `wx.requestPayment` 售卖数字点数。
- 不擅自启用小程序虚拟支付。
- 不创建真实订单，不展示付款按钮。
- 不通过 H5、公众号、二维码、客服或 Creem 美元支付绕过平台规则。
- 人民币点数包继续 `enabled=false`。
- `MINIAPP_PAYMENTS_ENABLED=false`、`PAYMENT_PROVIDER_WECHAT_ENABLED=false`、`WECHAT_PAY_MODE=disabled`。

首个审核版本仅允许已有点数和管理员发放的测试点数生成海报；无点数用户显示“海报点数购买暂未开放”。最终购买、退款、未成年人和 iOS/Android 规则需在支付产品分类确认后重新审核。
